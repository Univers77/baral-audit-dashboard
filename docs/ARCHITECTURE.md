# Arquitectura inicial

El diseño objetivo está en [el master](BARAL_CAMPAIGNOS_CODEX_OBSIDIAN_MASTER.md). Este bootstrap establece contratos en `campaign_os/schemas/`, datos separados bajo `data/`, memoria curada en `knowledge/obsidian-vault/` y gobernanza en `AGENTS.md`, `.agents/skills/` y `docs/`.

Aún no hay runtime, API, UI, base de datos, agentes ni conectores. Human Gate será obligatorio al implementar acciones externas.
