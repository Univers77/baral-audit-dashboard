# Gobernanza de datos

`data/raw/` guarda origen y se ignora por Git. `data/normalized/` contiene derivados; lo privado va en `data/normalized/private/`. `data/cache/` es descartable; revisar exports antes de compartir.

Obsidian guarda conocimiento curado, decisiones y aprendizajes con datos personales minimizados. No es almacén de comentarios. Registrar alcance y limitaciones de cada fuente; una muestra parcial no representa a Bolivia.
