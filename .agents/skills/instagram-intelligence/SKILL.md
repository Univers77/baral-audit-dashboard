# instagram-intelligence

## Activar cuando
Instagram forma parte del alcance de escucha o adaptación creativa.

## Flujo
1. Validar cuenta/asset autorizado, query, fechas y acceso permitido; no sortear restricciones.
2. Distinguir reel, story, caption, comentario y respuesta; registrar enlace/fecha si existen.
3. Reportar paginación, búsqueda, cobertura perdida y sesgo; la muestra no representa Bolivia.
4. Deduplicar y minimizar handles/PII.
5. Validar manualmente transcripciones críticas; texto aislado omite contexto audiovisual.
6. Para pieza 9:16 revisar hook, captions, safe areas, claim, CTA y recorte descontextualizado.

## Entrega
Fuente, periodo, cobertura, contenido normalizado y limitaciones. Nunca publicar ni interactuar automáticamente.
