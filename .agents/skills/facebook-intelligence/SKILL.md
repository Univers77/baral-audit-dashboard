# facebook-intelligence

## Activar cuando
Facebook forma parte de escucha, atención o medios.

## Límites
Graph API sobre activos propios/permisos aprobados o fuentes públicas accesibles y documentadas. No acceder a grupos privados, evadir controles ni automatizar interacciones. Confirmar versión/campos vigentes.

## Flujo
1. Separar páginas, anuncios, grupos públicos, comentarios y mensajes privados; estos últimos quedan fuera.
2. Registrar asset, responsable de permisos, alcance y periodo sin copiar tokens.
3. Minimizar IDs y datos personales; exportar solo texto/contexto necesario.
4. No inferir bot o mala fe desde crítica/identidad.
5. Para activos de cliente confirmar admin, política de marca, ruta de atención y aprobador.
6. Validar formato, texto, derechos, condiciones y anuncio como elementos separados.

## Entrega
Adaptador, permisos declarados, evidencia minimizada, temas y límites no evaluables.
